# Home server images

> **Deprecated.** This repository is no longer actively maintained, and new image versions will not be built or published.
>
> You are welcome to fork https://github.com/leterio/server-docker-images if you would like to keep building and maintaining these images yourself.

Some images that I use on my home server

* minidlna - A DLNA server for media sharing on network
* samba - File sharing server using SMB protocol
* wsdd - A Web Service Discovery deamon. Used for announcing SMB (samba) over LAN
